# 📱 Store Mobile Test

**Projeto de estudos em automação de testes mobile utilizando WebdriverIO e Appium.**

## 📌 Sobre o projeto

Este repositório tem como objetivo desenvolver conhecimentos em automação de testes para aplicações mobile, utilizando WebdriverIO integrado ao Appium.

O projeto reúne a estrutura inicial de configuração do ambiente de automação, organização dos testes e arquivos necessários para o desenvolvimento de testes automatizados mobile com JavaScript.

## 🎯 Objetivos

- Conhecer os fundamentos de automação de testes mobile.
- Configurar o ambiente utilizando WebdriverIO e Appium.
- Compreender a estrutura de projetos de automação mobile.
- Desenvolver testes automatizados utilizando JavaScript.
- Explorar a interação automatizada com elementos de aplicações mobile.
- Construir uma base para projetos de Mobile Test Automation.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| JavaScript | Linguagem de programação dos testes |
| WebdriverIO | Framework de automação |
| Appium | Automação de aplicações mobile |
| Node.js | Ambiente de execução JavaScript |
| npm | Gerenciamento de dependências |

### Arquivos principais

- **test/**: diretório destinado à organização dos testes automatizados.
- **wdio.conf.js**: arquivo de configuração do WebdriverIO.
- **package.json**: gerenciamento das dependências e scripts do projeto.
- **package-lock.json**: registro das versões das dependências instaladas.
